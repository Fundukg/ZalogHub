# ZalogHub Todo App

Простой, разработанный в рамках тестового задания для Junior Frontend Developer на React + TypeScript.


## Затраченное время

Ориентировочное время на выполнение: **1 час**.

## Инструкция по локальному запуску

Для запуска проекта на вашем устройстве потребуется установленный **Node.js**.

1.  Склонируйте репозиторий на свой компьютер.
2.  Откройте терминал в папке проекта.
3.  Установите необходимые зависимости командой:
    ```bash
    npm install
    ```
4.  Запустите сервер для разработки:
    ```bash
    npm run dev
    ```
5.  Откройте в браузере локальный адрес (обычно `http://localhost:5173/`).

## Реализованный функционал

1.  **Добавление задач:** Реализована валидация формы — пустые строки и строки, состоящие только из пробелов, блокируются.
2.  **Управление статусом:** Задачи переключаются между активными и выполненными с помощью чекбокса. Выполненные задачи визуально зачеркиваются.
3.  **Удаление:** Любую задачу можно удалить из списка.
4.  **Фильтрация:** Доступны три вкладки — "Все", "Активные" и "Выполненные", которые динамически фильтруют основной массив.
5.  **Персистентность:** Все изменения списка синхронизируются с `localStorage`. При обновлении страницы задачи остаются на своих местах.
